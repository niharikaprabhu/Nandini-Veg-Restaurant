# NRS Nandhini Hotel

A restaurant website showcasing traditional South Indian vegetarian cuisine, menu offerings, and restaurant information.

## Overview

NRS Nandhini Hotel is a front-end web development project created to establish an online presence for a vegetarian restaurant. The website focuses on presenting the restaurant's identity and menu through a clean, accessible, and user-friendly design.

## Features

- Restaurant introduction and homepage
- Menu organized into food categories
- Interactive menu navigation
- Restaurant information and contact section
- Navigation between website sections

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Objective

To develop a functional restaurant website while applying fundamental front-end development skills.
